# Feuille de route proposée

1. **Fiabiliser le prototype** : corriger les formulations qui présentent les calculs comme validés ; clarifier les unités et les hypothèses.
2. **Définir les données nécessaires** : site, niveaux d'eau, HMT, débit mesuré, conduite, pompe et courbe constructeur, contrôleur, champ PV, stockage et qualité d'eau.
3. **Améliorer le modèle** : pertes de charge, fonctionnement horaire, contraintes de pompe et production solaire, rendements séparés et scénarios saisonniers.
4. **Préparer la télémétrie** : définir capteurs, fréquence d'acquisition, format des données, stockage, gestion des erreurs et sécurité.
5. **Valider sur le terrain** : comparer les résultats aux mesures et documenter les essais avec des spécialistes.
6. **Ajouter un tableau de bord connecté** seulement lorsque les sources de données réelles et les règles de validation sont établies.

Cette feuille de route est une proposition de travail, pas une description de fonctionnalités déjà réalisées.
